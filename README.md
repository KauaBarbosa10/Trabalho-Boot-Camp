# Projeto da disciplina Bootcamp 1

# Portfólio Pessoal — Kauã Barbosa

## Sobre o Projeto

Este projeto foi desenvolvido como atividade da disciplina de Bootcamp 1 com o objetivo de criar um portfólio pessoal moderno, responsivo e funcional.

A aplicação foi construída para apresentar informações profissionais, habilidades técnicas, projetos desenvolvidos e meios de contato de forma organizada e visualmente agradável.

O projeto também teve como finalidade aplicar conhecimentos práticos de desenvolvimento front-end, estruturação de interfaces web e estilização responsiva utilizando tecnologias amplamente utilizadas no mercado.

A interface foi desenvolvida com foco em experiência do usuário, responsividade e identidade visual profissional.

---

# Objetivos do Projeto

* Apresentar informações profissionais de forma organizada
* Demonstrar conhecimentos em desenvolvimento front-end
* Exibir projetos pessoais e acadêmicos
* Disponibilizar canais de contato profissional
* Criar uma interface moderna e responsiva

---

# Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

## HTML5

Utilizado para estruturar semanticamente todo o conteúdo da aplicação.

## CSS3

Responsável pela estilização do site, responsividade, animações, efeitos visuais e organização do layout.

## JavaScript

Utilizado para implementar interações dinâmicas e funcionalidades do site.

## Font Awesome

Biblioteca utilizada para inserção de ícones profissionais e elementos visuais.

## Google Fonts

Utilizado para aplicação de tipografia personalizada na interface.

---

# Funcionalidades

## Página Inicial

Apresentação principal do portfólio com destaque para nome, descrição profissional e navegação entre seções.

## Seção Sobre

Área destinada à apresentação pessoal e profissional.

## Área de Projetos

Exibição de projetos em formato de cards interativos com rolagem horizontal.

## Seção de Habilidades

Apresentação das principais competências técnicas utilizadas no desenvolvimento.

## Área de Contato

Seção com informações profissionais para contato:

* E-mail
* Telefone
* LinkedIn
* GitHub

## Responsividade

O site foi desenvolvido para adaptação em diferentes tamanhos de tela, incluindo:

* Desktop
* Tablets
* Smartphones
